# Changelog

## v1.0.0 — 2026-11-01

First public release.

- Test design, Data & QC, Interpretation, Type curve, Compare, Deconvolution, r-z Simulator, IPR and FMB tabs
- Analytical models: vertical, fractured and limited-entry wells; homogeneous, dual-porosity and radial composite reservoirs; boundaries; multi-rate superposition; gas by pseudo-pressure
- Near-contact DST analysis: contacts, per-phase rates, phase-redistribution correction, coning consistency check
- Header-aware gauge import, linked pressure/rate record plots with draggable period boundaries
- Project save/open (.json) and PDF report export, which now work as normal browser downloads outside claude.ai
- jsPDF bundled locally, so the tool has no CDN dependency for reports
